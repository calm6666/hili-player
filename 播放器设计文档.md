# 极简 TypeScript 组件库设计文档（纯 h 函数版）

## 1. 项目目标

构建一个 **极致轻量、零抽象运行时开销** 的 UI 组件库，满足以下要求：

- **纯 TypeScript**，完整类型支持。
- **直接操作真实 DOM**，不引入虚拟 DOM Diff，性能等价于手写原生 JavaScript。
- 支持 **函数组件** 和 **类组件**。
- 提供 **指令 (Directives)** 机制，用于可复用的 DOM 行为扩展。
- 提供 **生命周期钩子**：`onBeforeMount`，`onMounted`，`onBeforeDestroy`，`onDestroyed`，不包含更新相关钩子。
- 支持 **子组件传递**（`children` 数组和具名插槽）。
- 支持 **服务端渲染 (SSR)**，输出 HTML 字符串，并保留客户端激活 (Hydration) 能力。
- 提供 **列表渲染辅助函数 `repeat`**，可基于 key 高效更新列表。
- 安全处理外部 SVG 内容，通过 `svgContent` 属性注入清洗后的 DOM。
- 提供 **`show` 指令** 和 **条件渲染** 两种方式处理元素显隐。
- 核心代码量控制在 **450 行以内**。

---

## 2. 核心设计理念

整个库围绕 **虚拟节点描述 (VNode)**，但它仅在以下阶段存在：

1. 挂载前用于描述 DOM 结构（`h` 函数的返回值）。
2. 服务端渲染时用于生成 HTML 字符串。
3. 客户端首次挂载 (`mount`) 时用于一次性生成真实 DOM。

**一旦挂载完成，所有后续更新完全由开发者通过预先保存的真实 DOM 引用 (`ref`) 直接调用原生 API 完成，库本身不参与任何更新过程。** 因此运行时不存在任何 Diff、响应式追踪或批处理，性能与手写原生 JavaScript 完全一致。

## 3. 类型定义

```ts
// ---------------- VNode ----------------
interface VNode {
  tag: string | Component<any>;
  attrs: Record<string, any>;
  children: (VNode | string)[];
  el?: HTMLElement | Text;           // 挂载后对应的真实 DOM 节点
  lifecycle?: Lifecycle;             // 组件生命周期对象
  _cleanups?: (() => void)[];        // 指令和事件的清理函数
}

// ---------------- 组件 ----------------
type FnComponent<P = any> = (props: P) => VNode;

interface ClassComponent<P = any> {
  new (props: P): ComponentInstance<P>;
}

interface ComponentInstance<P = any> {
  props: P;
  el?: HTMLElement;
  render(): VNode;
  onBeforeMount?(): void;
  onMounted?(): void;
  onBeforeDestroy?(): void;
  onDestroyed?(): void;
}

type Component<P = any> = FnComponent<P> | ClassComponent<P>;

// ---------------- 生命周期 ----------------
interface Lifecycle {
  onBeforeMount?(): void;
  onMounted?(): void;
  onBeforeDestroy?(): void;
  onDestroyed?(): void;
}

// ---------------- 指令 ----------------
type Directive<T = any> = (el: HTMLElement, value: T) => (() => void) | void;
```

## 4. 核心 API 实现

### 4.1 `h(tag, attrs?, ...children)` → VNode

创建虚拟节点描述。自动识别组件和 SVG 元素。

```ts
const SVG_TAGS = new Set([
  'svg', 'circle', 'ellipse', 'line', 'path', 'polygon', 'polyline', 'rect',
  'text', 'tspan', 'g', 'defs', 'use', 'symbol', 'linearGradient', 'radialGradient',
  'stop', 'clipPath', 'mask', 'pattern', 'image', 'foreignObject'
]);

function h(
  tag: string | Component,
  attrs?: Record<string, any> | null,
  ...children: (VNode | string)[]
): VNode {
  const flatChildren = children.flat(Infinity).map(c =>
    typeof c === 'string' ? c : c
  ) as (VNode | string)[];

  // 组件处理
  if (typeof tag === 'function') {
    const props = { ...(attrs || {}), children: flatChildren };
    if (isClassComponent(tag)) {
      const instance = new tag(props);
      const vnode = instance.render();
      vnode.lifecycle = instance;  // 将实例作为生命周期对象注入
      return vnode;
    } else {
      return (tag as FnComponent)(props);
    }
  }

  // 普通元素
  const vnode: VNode = {
    tag,
    attrs: attrs || {},
    children: flatChildren,
  };

  // SVG 标签自动标记命名空间
  if (typeof tag === 'string' && SVG_TAGS.has(tag)) {
    vnode.attrs.xmlns = vnode.attrs.xmlns || 'http://www.w3.org/2000/svg';
    (vnode as any).__ns = vnode.attrs.xmlns;
  }

  return vnode;
}

function isClassComponent(fn: any): fn is ClassComponent {
  return typeof fn === 'function' && fn.prototype && typeof fn.prototype.render === 'function';
}
```

### 4.2 `mount(vnode, container)` → void

将 VNode 转换为真实 DOM 并插入容器，触发生命周期。

```ts
function mount(vnode: VNode | string, container: HTMLElement): void {
  const el = materialize(vnode);
  container.appendChild(el);
  invokeLifecycle(vnode, 'onBeforeMount');
  invokeLifecycle(vnode, 'onMounted');
}
```

### 4.3 `materialize(vnode)` → Node

递归将 VNode 转换为真实 DOM。根据是否有 SVG 命名空间调用 `createElementNS` 或 `createElement`。

```ts
function materialize(vnode: VNode | string): Node {
  if (typeof vnode === 'string') {
    return document.createTextNode(vnode);
  }

  const ns = (vnode as any).__ns;
  const el = ns
    ? document.createElementNS(ns, vnode.tag as string)
    : document.createElement(vnode.tag as string);

  applyAttrs(el as HTMLElement, vnode.attrs, vnode);

  for (const child of vnode.children) {
    el.appendChild(materialize(child));
  }

  vnode.el = el as HTMLElement;
  return el;
}
```

### 4.4 `applyAttrs(el, attrs, vnode)` → void

处理属性、事件、指令、ref、样式、SVG 内容等，并收集清理函数。

```ts
function applyAttrs(el: HTMLElement, attrs: Record<string, any>, vnode: VNode): void {
  const isSvg = el.namespaceURI === 'http://www.w3.org/2000/svg';
  const cleanups: (() => void)[] = [];

  for (const key in attrs) {
    if (!attrs.hasOwnProperty(key)) continue;
    const value = attrs[key];

    if (key === 'directives') {
      // 指令数组：二维数组 [[directiveFn, value], ...]
      if (Array.isArray(value)) {
        for (const [dir, val] of value) {
          const cleanup = dir(el, val);
          if (cleanup) cleanups.push(cleanup);
        }
      }
    } else if (key === 'svgContent') {
      // 安全注入 SVG 内容
      const fragment = parseSafeSVG(value);
      el.appendChild(fragment);
    } else if (key.startsWith('on')) {
      // 事件处理
      const event = key.slice(2).toLowerCase();
      const handler = value as EventListener;
      el.addEventListener(event, handler);
      cleanups.push(() => el.removeEventListener(event, handler));
    } else if (key === 'style' && typeof value === 'object') {
      Object.assign(el.style, value);
    } else if (key === 'ref' && typeof value === 'function') {
      value(el);
    } else {
      // 普通属性
      if (isSvg || key === 'class' || key === 'className') {
        el.setAttribute(key === 'className' ? 'class' : key, String(value));
      } else if (key in el) {
        (el as any)[key] = value;
      } else {
        el.setAttribute(key, String(value));
      }
    }
  }

  vnode._cleanups = cleanups;
}
```

### 4.5 `destroy(vnode)` → void

递归销毁组件树：触发销毁生命周期、执行清理函数、移除 DOM 节点。

```ts
function destroy(vnode: VNode | string): void {
  if (typeof vnode === 'string') return;

  invokeLifecycle(vnode, 'onBeforeDestroy');

  vnode._cleanups?.forEach(fn => fn());

  for (const child of vnode.children) {
    destroy(child);
  }

  vnode.el?.parentNode?.removeChild(vnode.el);

  invokeLifecycle(vnode, 'onDestroyed');
}

function invokeLifecycle(vnode: VNode | string, method: keyof Lifecycle): void {
  if (typeof vnode === 'string') return;
  vnode.lifecycle?.[method]?.();
  for (const child of vnode.children) {
    invokeLifecycle(child, method);
  }
}
```

## 5. 函数组件与生命周期绑定

函数组件通过 `defineComponent` 获得生命周期。内部创建一个 `Lifecycle` 对象并注入到 VNode。

```ts
function defineComponent<P>(
  setup: (props: P, lifecycle: Lifecycle) => VNode
): FnComponent<P> {
  return (props: P) => {
    const lc: Lifecycle = {};
    const vnode = setup(props, lc);
    vnode.lifecycle = lc;
    return vnode;
  };
}
```

**使用示例：**

```ts
const Clock = defineComponent<{ start: number }>((props, lc) => {
  let timer: number;
  lc.onMounted = () => {
    let sec = props.start;
    const el = document.getElementById('clock-display')!;
    timer = window.setInterval(() => {
      sec--;
      el.textContent = String(sec);
    }, 1000);
  };
  lc.onBeforeDestroy = () => clearInterval(timer);
  return h('div', { id: 'clock-display' }, String(props.start));
});
```

## 6. 类组件基类

提供 `BaseComponent` 抽象类，封装挂载、更新和生命周期，子类只需实现 `render`。

```ts
abstract class BaseComponent<P = any> implements ComponentInstance<P> {
  abstract props: P;
  el?: HTMLElement;

  abstract render(): VNode;

  mount(container: HTMLElement): void {
    const vnode = this.render();
    vnode.lifecycle = this;
    mount(vnode, container);
    this.el = vnode.el as HTMLElement;
  }

  // 全量更新根节点（作为后备，推荐使用 ref 局部更新）
  update(): void {
    const newVNode = this.render();
    newVNode.lifecycle = this;
    const newEl = materialize(newVNode);
    this.el?.replaceWith(newEl);
    this.el = newEl as HTMLElement;
  }

  onBeforeMount(): void {}
  onMounted(): void {}
  onBeforeDestroy(): void {}
  onDestroyed(): void {}
}
```

## 7. 指令系统

指令是接收元素和值的函数，可选返回清理函数。挂载时执行，销毁时自动调用清理函数。

### 7.1 内置指令

```ts
// 自动聚焦
const focus: Directive<boolean> = (el, value) => {
  if (value) setTimeout(() => (el as HTMLInputElement).focus(), 0);
};

// 点击外部触发回调
const clickOutside: Directive<() => void> = (el, callback) => {
  const handler = (e: MouseEvent) => {
    if (!el.contains(e.target as Node)) callback();
  };
  document.addEventListener('click', handler);
  return () => document.removeEventListener('click', handler);
};

// 显示/隐藏（类似 v-show）
const show: Directive<boolean> = (el, value) => {
  el.style.display = value ? '' : 'none';
};
```

**使用指令：**

```ts
h('input', {
  directives: [
    [focus, true],
    [clickOutside, () => console.log('clicked outside')]
  ]
});
```

### 7.2 条件渲染 (类 `v-if`)

`v-if` 不封装为指令，直接使用 JavaScript 条件语句。因为组件本身就是返回 VNode 的函数，条件渲染更直观且无额外指令开销。

```ts
function ConditionalPanel({ visible }: { visible: boolean }): VNode {
  return h('div', { class: 'panel' },
    visible ? h('p', {}, 'I am visible') : null
  );
}
```

如果非要用指令，可以按之前的占位符方式扩展，但这不是推荐做法。在文档中我们明确：条件渲染通过 JS 表达式完成。

## 8. 列表渲染辅助函数 `repeat`

提供一个轻量的 `repeat` 函数，基于 key 复用 DOM 节点并执行最小量移动/增删，不做属性 Diff。这样既能保持高性能，又能简化列表场景。

```ts
function repeat<T>(
  container: HTMLElement,
  items: T[],
  render: (item: T, index: number) => VNode,
  keyFn: (item: T) => any
): void {
  const oldNodes = Array.from(container.children) as HTMLElement[];
  const oldKeys = oldNodes.map((node: any) => node.__key);
  const newKeys = items.map(keyFn);

  const newNodes: Node[] = [];
  for (let i = 0; i < items.length; i++) {
    const key = newKeys[i];
    const idx = oldKeys.indexOf(key);
    if (idx !== -1) {
      newNodes.push(oldNodes[idx]);
    } else {
      const vnode = render(items[i], i);
      const node = materialize(vnode);
      (node as any).__key = key;
      newNodes.push(node);
    }
  }

  container.innerHTML = '';
  newNodes.forEach(n => container.appendChild(n));
}
```

## 9. 安全 SVG 处理

通过 `svgContent` 属性注入外部 SVG 字符串，内部使用 `DOMParser` 解析并清除脚本和事件属性。

```ts
function parseSafeSVG(svgString: string): DocumentFragment {
  const parser = new DOMParser();
  const doc = parser.parseFromString(svgString, 'image/svg+xml');
  const root = doc.documentElement;

  if (!root || root.nodeName !== 'svg') {
    return document.createDocumentFragment();
  }

  removeUnsafeNodes(root);

  const fragment = document.createDocumentFragment();
  fragment.appendChild(document.importNode(root, true));
  return fragment;
}

function removeUnsafeNodes(node: Node): void {
  if (node.nodeType === 1) {
    const el = node as Element;
    if (['script', 'use', 'foreignObject'].includes(el.tagName.toLowerCase())) {
      el.parentNode?.removeChild(el);
      return;
    }
    Array.from(el.attributes).forEach(attr => {
      if (
        attr.name.startsWith('on') ||
        (attr.name === 'href' && attr.value.toLowerCase().startsWith('javascript:'))
      ) {
        el.removeAttribute(attr.name);
      }
    });
    Array.from(el.childNodes).forEach(removeUnsafeNodes);
  }
}
```

**使用：**

```ts
import iconHome from './icons/home.svg?raw'; // 构建工具返回的字符串

function IconButton(): VNode {
  return h('button', { class: 'icon-btn' },
    h('span', { svgContent: iconHome })
  );
}
```

## 10. 服务端渲染 (SSR)

### 10.1 `renderToString` 函数

将 VNode 树序列化为 HTML 字符串。对于组件，调用其 `render` 方法获得 VNode 再递归。

```ts
function renderToString(vnode: VNode | string): string {
  if (typeof vnode === 'string') return escapeHtml(vnode);

  if (typeof vnode.tag === 'function') {
    const props = { ...vnode.attrs, children: vnode.children };
    let result: VNode;
    if (isClassComponent(vnode.tag)) {
      result = new vnode.tag(props).render();
    } else {
      result = (vnode.tag as FnComponent)(props);
    }
    return renderToString(result);
  }

  let html = `<${vnode.tag}${serializeAttrs(vnode.attrs)}>`;

  if (vnode.attrs.svgContent) {
    // 清洗后直接输出 SVG 内容
    const cleaned = vnode.attrs.svgContent.replace(
      /<script\b[^<]*(?:(?!<\/script>)<[^<]*)*<\/script>/gi,
      ''
    );
    html += cleaned;
  } else {
    html += vnode.children.map(child => renderToString(child)).join('');
  }

  html += `</${vnode.tag}>`;
  return html;
}

function escapeHtml(s: string): string {
  return s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;');
}

function serializeAttrs(attrs: Record<string, any>): string {
  let str = '';
  for (const key in attrs) {
    if (['directives', 'ref', 'svgContent'].includes(key) || key.startsWith('on')) continue;
    const val = attrs[key];
    if (val === true) {
      str += ` ${key}`;
    } else if (val !== false && val != null) {
      str += ` ${key}="${String(val).replace(/"/g, '&quot;')}"`;
    }
  }
  return str;
}
```

## 11. 完整示例：任务管理应用

下面示例展示了深层嵌套、列表增删改、指令、生命周期、SVG 图标等所有特性，且全部使用纯 `h` 函数。

```ts
// =============== 指令 ===============
const focus: Directive<boolean> = (el, value) => {
  if (value) setTimeout(() => (el as HTMLInputElement).focus(), 0);
};

// =============== 任务组件 (类组件) ===============
class TaskApp implements ComponentInstance<{}> {
  props = {};
  el?: HTMLElement;
  private inputEl?: HTMLInputElement;
  private listEl?: HTMLElement;
  private tasks: { text: string; done: boolean }[] = [];

  render(): VNode {
    return h('div', { class: 'task-app' },
      h('h2', {}, 'Task Manager'),
      h('div', { class: 'input-area' },
        h('input', {
          ref: (el: HTMLInputElement) => this.inputEl = el,
          placeholder: 'Enter task...',
          directives: [[focus, true]],
          onKeyDown: (e: KeyboardEvent) => {
            if (e.key === 'Enter') this.addTask();
          }
        }),
        h('button', { onClick: () => this.addTask() }, 'Add')
      ),
      h('ul', {
        ref: (el: HTMLElement) => {
          this.listEl = el;
          this.renderList();
        }
      })
    );
  }

  // ====== 操作方法 ======
  private addTask(): void {
    const text = this.inputEl?.value.trim();
    if (!text) return;
    this.tasks.push({ text, done: false });
    this.appendTaskItem(text);
    this.inputEl!.value = '';
  }

  private removeTask(index: number): void {
    this.tasks.splice(index, 1);
    (this.listEl!.children[index] as HTMLElement).remove();
  }

  private toggleDone(index: number): void {
    this.tasks[index].done = !this.tasks[index].done;
    const li = this.listEl!.children[index] as HTMLElement;
    li.classList.toggle('done', this.tasks[index].done);
  }

  private renderList(): void {
    if (!this.listEl) return;
    this.listEl.innerHTML = '';
    this.tasks.forEach((t, i) => this.appendTaskItem(t.text, i));
  }

  private appendTaskItem(text: string, index?: number): void {
    const idx = index ?? this.tasks.length - 1;
    const item = h('li', { class: this.tasks[idx]?.done ? 'task done' : 'task' },
      h('input', {
        type: 'checkbox',
        checked: this.tasks[idx]?.done ?? false,
        onChange: () => this.toggleDone(idx)
      }),
      h('span', { class: 'task-text' }, text),
      h('button', {
        class: 'delete-btn',
        onClick: () => this.removeTask(idx)
      }, '×')
    );
    this.listEl!.appendChild(materialize(item));
  }

  // 生命周期示例
  onMounted() { console.log('TaskApp mounted'); }
  onBeforeDestroy() { console.log('TaskApp will be destroyed'); }
}

// =============== 布局组件 (函数组件) ===============
function Layout(props: { header: VNode; sidebar: VNode; main: VNode }): VNode {
  return h('div', { class: 'layout' },
    h('header', {}, props.header),
    h('div', { class: 'body' },
      h('aside', {}, props.sidebar),
      h('main', {}, props.main)
    )
  );
}

// =============== 应用入口 ===============
function App(): VNode {
  return h(Layout, {
    header: h('h1', {}, 'My App'),
    sidebar: h('nav', {},
      h('a', { href: '#home' }, 'Home'),
      h('a', { href: '#tasks' }, 'Tasks')
    ),
    main: h(TaskApp, {})
  });
}

// =============== 启动 ===============
mount(h(App, {}), document.getElementById('root')!);
```

## 12. 性能与安全保证

- **运行时性能**：首次挂载通过原生 DOM API 一次性生成节点，后续所有更新（增、删、改类名、样式、文本）都由开发者通过保存的 DOM 引用直接调用原生 API，库零介入。因此性能与手写原生 JS 无异。
- **服务端渲染**：`renderToString` 仅在服务端构建时执行一次，客户端 `hydrate` 复用已有 DOM，仅绑定行为，无 DOM 重建。
- **SVG 安全**：所有通过 `svgContent` 传入的 SVG 字符串均经 `DOMParser` 解析并清除脚本和事件属性，杜绝 XSS 风险。
